# kit-opencode

Kit para trabajar las webs de Rednet con **OpenCode** en otro notebook, sin Claude.

- Empieza por **[GUIA-INSTALACION.md](GUIA-INSTALACION.md)**.
- Instaladores: `instalar-windows.ps1` y `instalar-mac-linux.sh`.
- Modelo recomendado: [MODELOS.md](MODELOS.md).
- Reglas que se van sumando: [BITACORA.md](BITACORA.md).

Lo que OpenCode carga está en la raíz del repo: `AGENTS.md`, `opencode.jsonc` y `.opencode/` (agentes, comandos y skills).
